# smarthome-technikerprojekt

Öffentliches Hauptrepo für das Smart-Home-Technikerprojekt.

## Ziel
Lokales, modulares Smart-Home-System mit:
- ESP-NOW zwischen dezentralen Modulen und Master
- MQTT zwischen Master und Server
- Node-RED Web-Dashboard
- klar getrennten Basistypen und konkreten Geräten

## Struktur
- `docs/public/` Öffentliche technische Dokumentation
- `firmware/` Firmware für Basistypen und Geräte
- `server/` MQTT/Node-RED-Serverstruktur
- `hardware/` KiCad und Hardware-Dokumentation pro Basistyp
- `tests/` Teststruktur und Nachweise
- `PROTOKOLL/` Projektprotokolle der offiziellen Linie
