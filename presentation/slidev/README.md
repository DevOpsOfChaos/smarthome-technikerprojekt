# Slidev-Praesentation

Erste Slidev-Fassung fuer den Technikerprojekt-Vortrag.

## Ziel

Die Praesentation zeigt den lokalen Systempfad:

- Geraet
- Master
- MQTT/JSON
- Node-RED/SQLite
- Dashboard
- ACK/State
- Testnachweis

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Export

```bash
npm run export
```

## Struktur

- `slides.md`: Hauptpraesentation
- `notes/speaker-notes.md`: Sprecherleitfaden
- `public/images/`: spaeter gepruefte Bilder

## Leitplanken

Der Hauptvortrag bleibt bei 10 Folien. Backup-Folien sind nur fuer Demo-Fallback und Prueferfragen gedacht.

Vor dem Einbinden von Bildern und Videos muessen die Medien manuell geprueft werden.
